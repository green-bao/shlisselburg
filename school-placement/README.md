# Размещение школ в Шлиссельбурге

Локальное приложение практики 3 сравнивает обеспеченность населения местами в школах при разных вариантах их размещения. Используются сохранённые данные практики 2: 97 кварталов, расчётное население, два существующих школьных корпуса и матрицы времени в пути. Данные города повторно скачивать не требуется.

## Запуск

Откройте корневую папку репозитория в VS Code. Для первого запуска создайте окружение Python 3.12 и установите библиотеки:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r school-placement\requirements.txt
```

Запустите приложение:

```powershell
.\.venv\Scripts\python.exe school-placement\app.py
```

Затем откройте в браузере [приложение](http://127.0.0.1:8765). Окно терминала должно оставаться открытым. Для завершения нажмите в нём Ctrl+C. Другой порт можно задать так:

```powershell
.\.venv\Scripts\python.exe school-placement\app.py --port 8766
```

Приложение использует Python и библиотеки из папки `.venv` учебного проекта. Обычно они уже установлены. Если библиотек не хватает, их можно восстановить по списку `requirements.txt`:

```powershell
.\.venv\Scripts\python.exe -m pip install -r school-placement\requirements.txt
```

Сервер доступен только на этом компьютере. Карта, расчёт и интерфейс работают локально, без платных сервисов и обращения к языковой модели.

## Работа с картой и сценариями

1. Выберите способ передвижения: пешком или на автомобиле. Исходный дефицит составляет соответственно 1145 и 269 мест. Сравнивайте варианты внутри одного режима.
2. Нажмите квартал на карте или выберите его номер в списке. В карточке появятся население, потребность, вместимость школ, обеспеченность и дефицит. Кнопки «+», «−» и «Обзор» меняют масштаб. На увеличенной карте показаны номера всех кварталов; в общем обзоре подписаны кварталы с населением и выбранные кварталы.
3. Укажите положительное целое число мест и нажмите «Добавить». Повторите для нескольких школ при необходимости.
4. Нажмите «Рассчитать сценарий». Карта и таблица обновятся для всей территории. Новая школа может изменить обеспеченность соседних кварталов. До расчёта изменения списка показываются отдельной подсказкой.
5. Переключайте карту между исходным состоянием, рассчитанным сценарием и изменением обеспеченности. Серый цвет означает «Потребность 0». Фиолетовый контур выделяет квартал с новой школой.
6. «Сбросить изменения» возвращает исходное состояние выбранного режима. «Сохранить CSV» выгружает сравнение по всем 97 кварталам для последнего рассчитанного сценария.

Для сохранения сценария введите название и основания выбора кварталов. Нажмите «Сохранить текущий». Сценарии остаются в этом браузере; кнопка «Сохранить JSON» создаёт переносимый файл. Через «Загрузить JSON» можно восстановить сценарии и результаты эксперимента. При загрузке результаты пересчитываются по локальным исходным данным. Таблица сохранённых сценариев показывает режим, новые школы, остаточный дефицит и его сокращение. Кнопка «Открыть» отображает выбранный вариант на карте.

## Автоматический поиск

Укажите вместимость одной школы и нажмите «Разместить автоматически». Поиск последовательно проверяет каждый из 97 кварталов и выбирает кварталы с наибольшим сокращением суммарного дефицита мест на всей территории. Каждый вариант начинается с существующих школ; добавления из текущего ручного сценария в поиск не переходят.

Прогресс показывает число проверенных кварталов. После завершения появится полный рейтинг и все равноценные лучшие кварталы. На карте отображается один из них. Чтобы посмотреть любой другой вариант, нажмите его строку в рейтинге. Рейтинг можно сохранить в CSV. При ошибке отдельного расчёта приложение показывает её и указывает, что полный перебор не выполнен.

## Эксперимент А/Б/В

Для своего эксперимента сначала выберите и сохраните ручные варианты: А - одна школа на 600 мест, Б - две школы по 300 мест. До запуска поиска запишите основания выбора. Затем выполните поиск для 600 мест и сохраните результат как В. Сравните остаточный дефицит, его сокращение и изменения по кварталам.

В папке `results\experiment` сохранены результаты эксперимента А/Б/В. Результаты обоих способов передвижения рассматриваются отдельно. Чтобы открыть сценарии, нажмите «Загрузить JSON» в разделе сохранённых сценариев и выберите `results\experiment\saved_scenarios.json`.

## Данные и метод

Исходные файлы приложения находятся в `data`, результаты сценариев - в `results`. Приложение использует локальные копии; материалы практики 2 остаются исходным комплектом для чтения.

Кварталы, здания и уличная сеть получены из OpenStreetMap. Население оценено по зданиям и жилой площади; при отсутствии сведений использована оценка 30 м² на человека. Учтены два корпуса одной школы: квартал 3 - 934 места, квартал 24 - 683 места. Вместимость взята из предоставленных сведений сайтов образовательных организаций; дата состояния этих сведений не установлена.

Расчёт повторяет `competitive_provision` из BlocksNet 1.0.0a9 с параметрами практики 2: 120 мест на 1000 жителей, порог 15 минут, `self_supply=True`, `max_depth=1`. Это учебные параметры модели. Строки матриц соответствуют кварталам жителей, столбцы - кварталам школ; время задано в минутах. Потребность округляется по кварталам способом исходного метода, поэтому её сумма составляет 1886 мест при исходной вместимости 1617 мест. Остаточный дефицит - неудовлетворённая расчётная потребность в местах с учётом вместимости и доступности школ.

Полнота OpenStreetMap, расчётное население, округление потребности и приближение времени в пути влияют на результаты. Пешая скорость принята 5 км/ч, автомобильные скорости заданы по типам дорог без пробок и поиска парковки. Расчёт использует время в пути между кварталами. Для конкретного участка требуется отдельная проверка маршрутов до входа в школу. Выбор земельного участка и возможность строительства требуют отдельного градостроительного обоснования.
